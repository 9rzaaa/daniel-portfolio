Academic Context & Scope

2nd-Year Course Guidelines & Standards

Rather than a commercial production release, EASY&CO was engineered to fulfill specific 2nd-year Application Development (AD-) rubric requirements set by our professor — emphasizing strict Git branching conventions, reusable UI view fragmentation, database migrations & seeders, and built-in Moodboard (/mb) and Roadmap (/rm) design pages.

Functional Architecture

End-to-End Condo Booking Workflow

Covers the complete reservation lifecycle for a botanical studio unit in Quezon City: date availability checking, guest capacity validation, nightly & cleaning fee calculation, simulated e-wallet checkout (GCash, Maya, QR Ph), and role-guarded administrative CRUD for users and unit bookings.

Coursework Deliverables

Core Modules & Guidelines Implemented

Condo Booking Engine

  • Interactive Date Conflict Check: Flatpickr calendar fetches active bookings via AJAX (/booking/get-booked-dates) to prevent double-booking.
  • Dynamic Price Calculation: Server-side pricing computes nights, base nightly rate, and cleaning fees while enforcing guest limits.
  • Digital Payment Simulation: Supports GCash, Maya, and QR Ph checkout flows with generated transaction IDs (TXN-...).
  • My Bookings Portal: Guests can review upcoming, pending, completed, and cancelled reservations and cancel eligible stays.

Admin Console & CRUD

  • Dashboard KPI Cards: Summarizes All Earnings, Active Confirmed Bookings, Total Registered Users, and Monthly Booking Growth.
  • Unit Booking Management: Search and filter reservations by status or date range, inspect details, and update booking statuses.
  • User Management CRUD: Dedicated admin module (/test/user) to create, edit, and soft-delete user accounts via modal forms.
  • Role-Based Session Guard: Separates admin and client sessions with automatic login redirect preservation.

Academic Design & Standards

  • Modular View Fragmentation: Decomposes pages into reusable CI4 view components (components/head, header, cards, cta, modals).
  • Interactive Moodboard (/mb): Showcases the botanical color palette, typography hierarchy, button states, and logo variations.
  • Project Roadmap (/rm): Documents milestone deliverables from database schema design to frontend fragmentation.
  • Migrations & Seeders: Reproducible schema setup for users, properties, bookings, and payments tables.
